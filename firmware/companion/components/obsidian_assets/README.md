# Obsidian display assets

This component contains the display resources for the 466 x 466 Pocket-Code
Obsidian face.  It has no runtime network dependency: the face, provider
textures, provider glyphs, and Inter subsets are compiled into the component.

## Public contract

`include/obsidian_assets.h` declares these LVGL 9 resources with C linkage:

| Resource | LVGL format | Dimensions | Purpose |
| --- | --- | --- | --- |
| `pc_obsidian_background` | `LV_COLOR_FORMAT_RGB565` | 466 x 466 | Opaque Obsidian atmosphere, tracks, liquid lens, and rim |
| `pc_ring_codex`, `pc_ring_claude`, `pc_ring_grok` | `LV_COLOR_FORMAT_RGB565` | 466 x 466 | Full-face provider gradients for native arc masking |
| `pc_glyph_codex`, `pc_glyph_claude`, `pc_glyph_grok` | `LV_COLOR_FORMAT_A8` | 18 x 18 | Alpha-only provider marks, recolored by LVGL |
| `pc_inter_64`, `pc_inter_84`, `pc_inter_34` | LVGL bitmap font, 4 bpp | — | `.-0123456789KMBT` |
| `pc_inter_22`, `pc_inter_18`, `pc_inter_17`, `pc_inter_14`, `pc_inter_11` | LVGL bitmap font, 4 bpp | — | ASCII 32 through 126 |

The face and ring images use a 932-byte row stride and native little-endian
RGB565 bytes.  The background is opaque black for every pixel outside the
circular edge, including the square corners.  The ring textures are full-face
images so an arc can mask them without changing color around the circumference.
Their gradient coordinate is `t = (x + y) / (2 * 465)`, with the same sRGB stop
positions and colors as the approved SVG gradients.

## Reproducible generation

The vendored `source/pocket-code-liquid-studio.html` is the approved preview
fragment (SHA-256:
`8f8dd578af1d48bc9667a1a023b24010be44e56c90a0e82240b8a48c5dbe7ede`).
The exact capture used the existing review wrapper at
`/tmp/pocket-code-liquid-review.html` (SHA-256:
`0f86e17a21213dd35c222bd98160acc0e0e35156150d64ae673662afd311adac`).  Provide
that wrapper explicitly when reproducing it:

```sh
cd firmware/companion/components/obsidian_assets
NODE_PATH=/path/to/workspace/node_modules \
PLAYWRIGHT_CHROMIUM=/path/to/chrome-headless-shell \
  node tools/generate_assets.cjs \
  --preview source/pocket-code-liquid-studio.html \
  --wrapper /tmp/pocket-code-liquid-review.html
```

The script waits for `data-engine="liquid-glass-react"` in the actual iframe,
sets `--pc-fit: 1`, and verifies a 466 x 466 stage bounding box.  It removes
the lens content, glyphs, active SVG paths, endcaps, and sweep while retaining
the Obsidian atmosphere, light ribbons, liquid lens, rim, and `pcs-track`
circles.  It allows three animation frames for LiquidGlass's measured filter
dimensions before capturing the stage.  A portable in-memory iframe is used
when `--wrapper` is omitted.

Fonts are generated by the pinned `lv_font_conv@1.5.3` package with 4-bit
antialiasing and `--no-compress`, because the maintained ESP-IDF configuration
keeps `LV_USE_FONT_COMPRESSED` disabled.  The script passes `--lv-include
lvgl.h` and emits one C source per public font symbol.  The source font and
licenses are retained under `source/`:

- `source/Inter-Regular.ttf` is Inter 4.1 Regular (SHA-256
  `40d692fce188e4471e2b3cba937be967878f631ad3ebbbdcd587687c7ebe0c82`), under
  `source/INTER-OFL.txt`.
- `source/icons/openai.svg`, `claude.svg`, and `grok.svg` are the exact pinned
  files from
  `https://cdn.jsdelivr.net/npm/@lobehub/icons-static-svg@1.95.0/icons/` under
  `source/LOBHUB-ICONS-MIT.txt`.

Only the generator needs Node, Playwright, Sharp, PNGJS, and network access.
The firmware component links the generated C data and does not fetch any
provider, font, or image resource at runtime.
